# MIG145 Pro / ACDC TIG225 Pro Demo Test Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create two independent PHY62XX BLE-UART demo projects implementing the
latest MIG145 Pro and ACDC TIG225 Pro protocols, with hardware-free simulation
enabled by default.

**Architecture:** Each project is a self-contained copy of the proven
`BTC_500DP_PRO_demo_test` bridge. A protocol-specific configuration header,
UART protocol module, simulation module, and BLE bridge isolate machine-specific
rules while preserving the existing OSAL and GATT structure.

**Tech Stack:** PHY62XX SDK 3.1.5, C, Keil MDK/ARMCC, GCC Makefile, OSAL, BLE
Peripheral, UART1, Python standard-library contract tests.

- [ ] **Step 2: Implement frame and checksum validation**

```c
static uint8 bys_packet_valid(const uint8 *pkt)
{
    uint16 cmd = BUILD_UINT16(pkt[4], pkt[5]);
    uint16 data = BUILD_UINT16(pkt[6], pkt[7]);
    uint16 checksum = BUILD_UINT16(pkt[8], pkt[9]);
    return pkt[0] == 0xAAu && pkt[1] == 0x55u &&
           pkt[10] == 0xBBu && pkt[11] == 0x55u &&
           checksum == (uint16)(cmd + data);
}
```

- [ ] **Step 3: Implement documented setting-to-query mode translation**

```c
static uint16 setting_mode_to_state(uint16 value)

    if (value == 2u) return 0u; /* setting MIG -> query MIG */
    return 1u;                  /* LIFT TIG is shared */
}
```

```c
{
    if (!tig_mode_supports_spot(state->mode) && state->t2t4_spot == 2u)
```
