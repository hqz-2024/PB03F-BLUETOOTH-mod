# ACDC TIG225 PRO Demo Test

基于 PHY62XX SDK 3.1.5 的 ACDC TIG225 Pro BLE-UART 通讯测试工程。

协议文档中的 TIG225 与 TIG215 为同一设备，设备上报类型统一为 `0x0009`。

## 1. 工作模式

工程默认在 `source/bys_bridge.h` 中开启：

```c
#define BYS_TEST_MODE
```

测试模式下不需要连接焊机：

- 每 100 ms 模拟一条协议查询响应，按 21 项查询循环。
- App 写入 FFE1 后更新模拟状态并返回对应的 `0x8x00` 确认包。
- P15 按下后随机刷新一组符合模式和输入电压范围的参数。
- P0 每 250 ms 翻转一次，作为运行心跳。

注释 `BYS_TEST_MODE` 后重新编译，工程切换为真实 ACDC TIG225 Pro
串口桥。

## 2. 接口参数

| 项目 | 配置 |
|---|---|
| UART | UART1，57600 8N0 |
| UART1 TX | P24 |
| UART1 RX | P23 |
| 调试 UART | UART0，P9 TX，P10 RX，115200 |
| BLE Service | `FFE0` |
| BLE Characteristic | `FFE1`，Read/Write/Notify |
| 数据长度 | 固定 12 字节 |
| 设备上报类型 | `0x0009` |
| BLE 广播名 | `BYS` |

`FFE2` 是预留遥控通道，当前测试工程不开放。TIG225 的本次协议文档未定义
OTA，因此本工程不增加额外 OTA 行为。

## 3. 数据包

```text
AA 55 | 设备类型 2B | 命令码 2B | 数据区 2B | 校验码 2B | BB 55
```

- 多字节整数使用小端序。
- 校验码 = `(命令码 + 数据区) & 0xFFFF`。
- PB03F 发给下位机时，设备类型字段为 `0x8000`。
- 设备上报时，设备类型字段为 `0x0009`。

示例：

```text
查询模式:
AA 55 00 00 02 00 00 00 02 00 BB 55

设备上报 TIG AC 三角波模式:
AA 55 09 00 82 00 03 00 85 00 BB 55

App 设置点焊时间 1.50 s:
AA 55 00 80 00 09 96 00 96 09 BB 55
```

## 4. 查询命令与值域

| 查询 | 响应 | 参数 | 值域 |
|---|---|---|---|
| `0x0002` | `0x0082` | 模式 | `0=STICK,1=TIG(DC),2=TIG(AC方波),3=TIG(AC三角波)` |
| `0x0003` | `0x0083` | 热引弧电流 | `0~100A`，`0=OFF` |
| `0x0004` | `0x0084` | 推力电流 | `0~100A`，`0=OFF` |
| `0x0005` | `0x0085` | VRD | `0=关,1=开` |
| `0x0006` | `0x0086` | 焊接电流 | 按模式和输入电压限制 |
| `0x0007` | `0x0087` | 2T/4T/点焊 | `0=2T,1=4T,2=点焊` |
| `0x0008` | `0x0088` | 脉冲 | `0=关,1=开` |
| `0x0009` | `0x0089` | 点焊时间 | `10~150`，即 `0.10~1.50s` |
| `0x000A` | `0x008A` | 前气时间 | `1~30`，即 `0.1~3.0s` |
| `0x000B` | `0x008B` | 起弧电流 | 110V `10~160A`，220V `10~225A` |
| `0x000C` | `0x008C` | 缓升时间 | `0~15s` |
| `0x000D` | `0x008D` | 脉冲占空比 | `10~90%` |
| `0x000E` | `0x008E` | 脉冲频率/三角波个数 | 普通模式 `5~2000`；三角波模式见第 6 节 |
| `0x000F` | `0x008F` | 脉冲谷值 | `5~95%` |
| `0x0010` | `0x0090` | AC 频率 | `40~200Hz` |
| `0x0011` | `0x0091` | AC 占空比 | `20~60%` |
| `0x0012` | `0x0092` | 缓降时间 | `0~25s` |
| `0x0013` | `0x0093` | 收弧电流 | 110V `10~160A`，220V `10~225A` |
| `0x0014` | `0x0094` | 后气时间 | `0~150`，即 `0.0~15.0s` |
| `0x0015` | `0x0095` | 报警 | `0=无报警,1=过流` |
| `0x0016` | `0x0096` | 输入电压 | `0=110V,1=220V` |

焊接电流范围：

| 模式 | 110V | 220V |
|---|---:|---:|
| STICK | `20~140A` | `20~180A` |
| TIG(DC)/AC方波/AC三角波 | `10~160A` | `10~225A` |

| `0x0F00` | `0x8F00` | 脉冲谷值 |
| `0x1000` | `0x9000` | AC 频率 |

非法值返回：

```text
命令码 0x8100，数据区 0x0001
```

测试模拟器在点焊模式下强制关闭脉冲；AC 方波和 AC 三角波模式不允许设置
点焊档。

## 6. 三角波模式

三角波模式下，命令 `0x000E` 的数值是三角波个数 `C`，不是直接显示的
三角波频率：

```text
10 <= C <= 2 * AC频率
C <= 400
```

固件测试 demo 只生成和接收合法的 `C`。三角波频率显示换算由 App 完成。

## 7. BLE 广播

广播保留 BTC demo 已验证的 31 字节 GAP 缓冲和 3 个 AD Structure。自定义
Manufacturer Data 字段顺序为：

| 偏移 | 字段 |
|---|---|
| 10-15 | BLE MAC，大端显示顺序 |
| 16-17 | 设备类型 `0x0009` |
| 18-19 | 焊接模式 |
| 20-21 | 2T/4T/点焊 |
| 22-23 | 焊接电流 |
| 24-25 | 脉冲开关 |
| 26-27 | 报警 |
| 28-29 | 输入电压 |
