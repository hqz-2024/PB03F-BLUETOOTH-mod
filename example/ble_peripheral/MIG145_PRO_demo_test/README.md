# MIG145 PRO Demo Test

基于 PHY62XX SDK 3.1.5 的 MIG145 Pro BLE-UART 通讯测试工程。

## 1. 工作模式

工程默认在 `source/bys_bridge.h` 中开启：

```c
#define BYS_TEST_MODE
```

测试模式下不需要连接焊机：

- 每 100 ms 模拟一条协议查询响应。
- App 写入 FFE1 后更新模拟状态并返回对应的 `0x8x00` 确认包。
- P15 按下后随机刷新一组符合协议范围的数据。
- P0 每 250 ms 翻转一次，作为运行心跳。

注释 `BYS_TEST_MODE` 后重新编译，工程切换为真实 MIG145 Pro 串口桥。

## 2. 接口参数

| 项目 | 配置 |
|---|---|
| UART | UART1，19200 8N0 |
| UART1 TX | P24 |
| UART1 RX | P23 |
| 调试 UART | UART0，P9 TX，P10 RX，115200 |
| BLE Service | `FFE0` |
| BLE Characteristic | `FFE1`，Read/Write/Notify |
| 数据长度 | 固定 12 字节 |
| 设备上报类型 | `0x0006` |
| BLE 广播名 | `BYS` |

`FFE2` 是协议预留的遥控通道，当前固件不开放。

## 3. 数据包

```text
AA 55 | 设备类型 2B | 命令码 2B | 数据区 2B | 校验码 2B | BB 55
```

- 多字节整数使用小端序。
- 校验码 = `(命令码 + 数据区) & 0xFFFF`。
- PB03F 发给下位机时，设备类型字段为 `0x8000`。
- 设备上报时，设备类型字段为 `0x0006`。

示例：

```text
查询模式:
AA 55 00 00 02 00 00 00 02 00 BB 55

设备上报 MIG 模式:
AA 55 06 00 82 00 00 00 82 00 BB 55

App 设置 MIG 电流 100 A:
AA 55 00 80 00 05 64 00 64 05 BB 55
```

## 4. 查询命令

| 查询 | 响应 | 参数 | 值域 |
|---|---|---|---|
| `0x0002` | `0x0082` | 模式 | `0=MIG,1=LIFT TIG,2=MMA` |
| `0x0003` | `0x0083` | 焊丝直径 | `0=0.030,1=0.035,2=0.040` |
| `0x0004` | `0x0084` | 智能模式 | `0=开,1=关` |
| `0x0005` | `0x0085` | MIG 电流 | 110V `50~125A`，220V `50~145A` |
| `0x0006` | `0x0086` | MIG 电压调节 | `0~60`，显示为 `-3.0~3.0V` |
| `0x0007` | `0x0087` | 2T/4T | `0=2T,1=4T` |
| `0x0008` | `0x0088` | TIG 电流 | 110V `10~125A`，220V `10~145A` |
| `0x0009` | `0x0089` | MMA 电流 | 110V `20~105A`，220V `20~125A` |
| `0x000A` | `0x008A` | VRD | `0=关,1=开` |
| `0x000B` | `0x008B` | MIG 实际电压 | 110V `13.5~23.2V`，220V `13.5~24.2V` |
| `0x000C` | `0x008C` | 报警 | `0=无,1=过流,2=过热` |
| `0x000D` | `0x008D` | 输入电压 | `0=110V,1=220V` |

## 5. 设置命令

| 设置 | 确认 | 参数 |
|---|---|---|
| `0x0200` | `0x8200` | 模式；设置表编码 `0=MMA,1=LIFT TIG,2=MIG` |
| `0x0300` | `0x8300` | 焊丝直径 |
| `0x0400` | `0x8400` | 智能模式 |
| `0x0500` | `0x8500` | MIG 电流 |
| `0x0600` | `0x8600` | MIG 电压调节 |
| `0x0700` | `0x8700` | 2T/4T |
| `0x0800` | `0x8800` | TIG 电流 |
| `0x0900` | `0x8900` | MMA 电流 |
| `0x0A00` | `0x8A00` | VRD |

协议设置表与查询表的 MIG/MMA 端点编码相反。测试模拟器按两张表分别翻译：
内部状态与查询响应使用 `0=MIG,1=LIFT TIG,2=MMA`；收到 `0x0200` 时按
`0=MMA,1=LIFT TIG,2=MIG` 转换，`0x8200` 确认包回显 App 原始值。

非法值返回：

```text
命令码 0x8100，数据区 0x0001
```

## 6. BLE 广播

广播保留 BTC demo 已验证的 31 字节 GAP 缓冲和 3 个 AD Structure。自定义
Manufacturer Data 字段顺序为：

| 偏移 | 字段 |
|---|---|
| 10-15 | BLE MAC，大端显示顺序 |
| 16-17 | 设备类型 `0x0006` |
| 18-19 | 工作模式 |
| 20-21 | 焊丝直径 |
| 22-23 | MIG 电流 |
| 24-25 | 2T/4T |
| 26-27 | 报警 |
| 28-29 | 输入电压 |

## 7. OTA

文档定义的 OTA 触发帧：

```text
AA 55 XX XX 00 FE FE 00 FE FE BB 55
```

- 命令码：`0xFE00`
- 数据区：`0x00FE`
- 触发后发送 3 个 50 ms 间隔的通知周期，然后软复位进入 OTA。
